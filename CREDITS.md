# Авторы и источники

- Исходный проект — [NBA2K-Randomizer-Android от AsdWELL](https://github.com/AsdWELL/NBA2K-Randomizer-Android). Из него перенесены правила подбора игроков, встроенные наборы данных и основа иконки приложения.
- Версия для iOS — [NBA2K-Randomizer-iOS](https://github.com/drewshich/NBA2K-Randomizer-iOS).
- Источник рейтингов, атрибутов и онлайн-карточек игроков — [2KRatings](https://www.2kratings.com/).
- Для разбора HTML используется [SwiftSoup](https://github.com/scinfu/SwiftSoup).

Права на материалы NBA, 2K и 2KRatings принадлежат соответствующим правообладателям. Указание источников не предоставляет разрешение на распространение этих материалов.
