# NBA 2K Randomizer для iOS

Приложение для случайного подбора баскетболистов и составов NBA 2K на iPhone. Требуется **iOS 17.0 или новее**.

Проект находится в разработке; проверка всех функций на реальном устройстве ещё продолжается.

## Возможности

- Одна или две команды по 1–5 игроков, подбор по позициям PG / SG / SF / PF / C.
- Игроки не повторяются до сброса колоды. Замены также расходуют колоду.
- История игр и замен сохраняется на телефоне отдельно для каждого ростера.
- Четыре встроенных ростера: текущие игроки и легенды NBA 2K25 / 2K26, по 100 игроков. Атрибуты и значки доступны без интернета, фотографии требуют загрузки.
- Поиск, фильтры по команде и позиции, сортировка по рейтингу, имени, команде, трёхочковым, данку и росту.
- Онлайн-ростер 2K27 и поиск на 2KRatings используют текущую версию сайта. Это HTML-парсинг, а не официальный API: при изменениях сайта онлайн-функции могут требовать доработки. Встроенные ростеры продолжают работать.

## Получить файл для iPhone без своего Mac

1. Создать свою копию репозитория через **Fork**.
2. В своей копии открыть **Actions → Build personal iPhone app**. При необходимости включить GitHub Actions.
3. Нажать **Run workflow** для ветки `main` и дождаться успешного завершения проверок и сборки.
4. Скачать артефакт **NBA2K-Randomizer-Personal** и распаковать ZIP. Внутри находится `NBA2K-Randomizer-Personal.ipa`.

Сборка выполняется на облачном Mac GitHub и запускается вручную.

В артефакте **iPhone-checks** сохраняются журналы и скриншоты тестового запуска. Срок хранения артефактов — 7 дней. Скачанный IPA не удаляется с вашего компьютера по истечении этого срока.

## Установить на свой iPhone с Windows

Для установки используется **[iLoader](https://iloader.app/)**.

1. Установить **iTunes для Windows** по ссылке в разделе Windows на [официальном сайте iLoader](https://iloader.app/). Он нужен для связи компьютера с iPhone.
2. Скачать и установить **iLoader для Windows** с того же сайта или из [официальных выпусков на GitHub](https://github.com/nab138/iloader/releases).
3. Подключить разблокированный iPhone кабелем, подтвердить «Доверять этому компьютеру» и при запросе ввести код-пароль телефона.
4. Открыть iLoader, выбрать подключённый iPhone и войти в свой **Apple Account**. Подтвердить вход кодом двухфакторной аутентификации, если он запрошен.
5. Выбрать **Import IPA**, указать `NBA2K-Randomizer-Personal.ipa` и дождаться установки. Для первой установки оставить настройки iLoader по умолчанию.
6. На iPhone открыть **Настройки → Основные → VPN и управление устройством**, выбрать профиль со своим Apple Account и подтвердить доверие, если iOS этого требует.
7. Включить **Настройки → Конфиденциальность и безопасность → Режим разработчика** и согласиться на перезагрузку. После перезагрузки разблокировать iPhone, подтвердить **«Включить»** в появившемся окне и ввести код-пароль. Затем открыть **NBA 2K Randomizer**. [Инструкция Apple по режиму разработчика](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).

Платная подписка Apple Developer, TestFlight и публикация в App Store не нужны. С бесплатным Apple Account подпись действует **7 дней**, одновременно можно установить до трёх таких приложений. [Ограничения бесплатной Personal Team у Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).

### Продление подписи

Подпись продлевается **вручную через iLoader**, до истечения семи дней или после него:

1. Подключить iPhone к компьютеру и открыть iLoader с тем же Apple Account.
2. Повторить **Import IPA** с сохранённым `NBA2K-Randomizer-Personal.ipa`.
3. Установить поверх существующего приложения с прежними настройками идентификатора приложения. Не удалять приложение перед этим, чтобы сохранить локальную историю.

Для продления подписи подходит уже скачанный IPA; новая облачная сборка нужна при изменении приложения. Автоматическое продление в текущей схеме не настроено.

## Проверки

- Проверка всех встроенных ростеров и соответствия карточек: `python tools/validate_data.py`.
- Тесты Swift: подбор позиций, отсутствие повторов, замены, сохранение истории, фильтры и HTML-парсер.
- Тест iPhone: запуск приложения, генерация состава и открытие ростера с сохранением скриншотов.

Для локальной сборки на Mac: `python3 tools/prepare_assets.py`, затем `xcodegen generate --spec ios/project.yml`. Дальше открыть сгенерированный `ios/NBA2KRandomizer.xcodeproj`. Проект настроен на сборку без подписи; личную подпись для установки добавляет iLoader.
